**Unnecessary explicit field naming**: Lines 42, 46, 50, 56, 64, 68 use `@strawberry.field(name="...")` to set GraphQL field names identical to the Python method names. Strawberry automatically converts snake_case method names to camelCase GraphQL field names, so `def salesorder_list(self)` already exposes as `salesorderList` in GraphQL without the explicit `name=` parameter. The `name=` parameter is only needed when you want the GraphQL name to differ from the Python name. Remove all six `name=` parameters — the resolvers will still work correctly and the code will be cleaner.
